# Project Horizon: WMS Vendor Selection & Implementation

*Note: This is a self-directed portfolio project simulating an end-to-end business analysis and vendor selection scenario. The company, vendors, and financial data are modeled for demonstration purposes.*

## 📌 Executive Summary
This project outlines the vendor selection and implementation strategy for Meridian Manufacturing & Logistics, a company transitioning from a discontinued, on-premise legacy Warehouse Management System (WMS). 

**The Decision:** After evaluating three vendors against 24 specific requirements, the mid-market solution (Warehouse360) was recommended over the cheapest option. While the budget option offered a higher ROI on paper, it failed a mandatory barcode scanning requirement—demonstrating that lowest cost does not always equal best business fit.
